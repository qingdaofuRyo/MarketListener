# ADR-0013：本机受控会话与已发布行情名单

状态：已实施；管理台入口按用户 2026-10-26 的新决定修订。

## 背景

产品会话需要防止本机其他页面直接取得产品权限。用户已明确要求本机内部管理台直接输入 IP 和端口访问，且取消浏览器口令；当前部署把本机操作者视为本机管理员。旧行情名单在请求中读取全市场尾部行情和金融指标，冷请求和正式写者可能竞争资源。

## 决定

产品页面仍经受控本机启动入口取得单次引导会话。内部管理台在服务已运行时允许本机浏览器以同源请求直接建立独立短期会话，无浏览器口令。Cookie 只在对应回环端口有效；产品和管理权限域隔离，管理会话不能由产品端取得。管理写请求匹配当前 Origin 与会话 CSRF 值；服务拒绝非回环监听、无效 Host 和代理身份头。快捷入口的当前 Windows 用户保护控制凭据仅供受控服务调用，不交给浏览器。

行情名单由更新边界生成包含完整行、来源依赖与真实版本的不可变发布文件，原子切换指针。请求只读取已发布行并过滤、排序和分页；文件缺失时给出可恢复状态，旧文件可用时明确标为 `STALE`。查询版本指实际读取快照，不能把旧文件标成新来源版本。正式来源与旧计算结果保留。

## 替代方案

仅凭回环 IP 允许写入无法区分本机其他页面。每页实时构建会重复读取大量分区，且来源更新期间可能混用版本。把读模型放入新数据库会增加正式写者和迁移成本。

## 后果与兼容

产品页面仍需本机受控入口取得会话；管理服务运行后，可从本机浏览器直接打开管理地址。管理直入意味着能使用该 Windows 桌面的本机操作者拥有内部管理能力；在启用局域网或多员工访问前必须另行设计身份验证和传输保护。非浏览器内部调用保留独立管理凭据。旧列表快照仍可审计，但只以已发布完整名单作为产品读取依据。首次构建、源版本变化和发布失败需在管理台显示进度或可恢复原因；性能指标须按真实设备和固定数据快照验收。
