# 客户产品与内部管理台分别提供网页入口和服务权限

用户于2026-10-01确认：现有8765网页面向产品客户，新增8766网页面向管理员、开发人员和测试人员，第一阶段管理台仅本机访问。采用独立前端入口、独立管理服务与服务端管理接口授权；内部管理台在客户服务停止时继续在线，负责管理其生命周期。取消继续开发独立Windows/macOS图形启动器的方向。

只更换导航标签或端口不足以隔离权限。客户入口保留行情、策略、个人数据与产品数据展示；服务启停、采集任务、供应商配置、内部日志和运行诊断由管理台访问。客户自己的策略、画线与账户数据编辑仍属于产品能力，不按HTTP写请求一律归入管理员功能。

本机阶段使用回环监听和内部服务凭据隔离管理调用，不把本机管理员身份描述为已实现的员工多用户登录。内网/公网阶段须另行完成员工身份、逐请求角色授权、客户数据归属和部署验证。该决定不改变Android离线签名包、行情与个人数据隔离、来源质量或策略执行边界。
