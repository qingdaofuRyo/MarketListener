# ADR-0010：策略计算、可视化与交易权限分层

MarketListener 将策略能力固定为策略函数、指标、策略三层：策略函数只做确定性无副作用计算，指标只把函数结果投影到图表，策略只引用函数和结构化规则而不依赖指标。桌面策略是唯一可产生 `OrderIntent` 的领域层，但订单意图必须依次经过风险引擎和执行适配器，策略不能直接调用券商或期货接口；在执行适配器未配置并验收前，实盘模式保持禁用。Android 继续遵守 ADR-0008，只解释签名的白名单 DSL 并产生观察信号，不产生订单意图。这一边界避免计算逻辑在指标与策略间复制，也阻止可视化或纯函数绕过风控进入交易执行。

## 后果

- 同一算法以稳定的策略函数 ID 和版本为唯一实现，指标和策略都通过注册表引用它。
- `Indicator` 与 `Strategy Function` 的运行上下文不暴露账户、持仓、订单、风险引擎或执行适配器。
- 回测、模拟和实盘使用相同的策略定义，但使用隔离的执行端口；回测结果不得标记为模拟或实盘结果。
- 不开发 Pine Script 兼容层，不允许 `eval()`、浏览器任意代码或未登记函数进入执行链。
