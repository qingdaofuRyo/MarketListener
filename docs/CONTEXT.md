# 行情监控和产业链图谱领域词汇

**本机产品会话（Local Product Session）**：由受控启动入口为当前 Windows 用户的产品页面建立、只适用于本机产品端口的短期浏览器会话；回环地址本身不能代表产品身份。
_Avoid_：把本机 IP 当用户身份、把管理凭据暴露给产品页面

**已发布行情名单（Published Market List）**：正式更新边界生成的不可变完整名单及原子版本指针。列表筛选和分页读取同一快照；旧快照须显示实际查询版本和待核对状态。
_Avoid_：请求时重算全市场、用当前发布版本标记旧快照

**个人资料备份（Personal Profile Backup）**：个人记录、策略、配置及发布清单的加密恢复副本；不包含大体积正式行情、数据源凭据或签名私钥。恢复前必须核验内容并预览对当前文件的影响。
_Avoid_：把个人备份视为行情全库备份、把加密备份等同于在用数据库加密

**通达信主连（TDX Main Series）**：
通达信期货通提供的主力月份连续价格序列；当前对应月份随通达信的换月选择改变，比较时必须使用同一交易日。
_Avoid_：项目自行按当日资金排名选取的月份、与不同日期月份报价比较

**通达信次连（TDX Secondary Series）**：
通达信期货通提供的次连价格序列；它的对应月份由该来源决定，不能未经来源核验称为当日持仓或沉淀资金排名第二的月份。
_Avoid_：固定次月合约、项目自行排序的第二大持仓合约

**旧通用连续条目（Legacy Generic Continuous Entry）**：
与明确的主连、次连和加权序列分别存在的旧连续报价条目，例如豆一连续A0、豆二连续B0。
_Avoid_：用“连续合约”统称所有主连、次连和加权序列

**官方期货名义市值（Official Futures Notional Value）**：
期货数据页用同一实际合约、同一交易日的官网结算价×有效乘数×官网单边持仓量得到的单边规模；不是账户资产。

**通达信期货名义市值（TDX Futures Notional Value）**：
全部行情页用通达信期货通同日结算价与单边持仓量、官网有效乘数得到的单边规模；与官方期货名义市值保留各自来源和差异。

**合约日来源差异待核验（Contract-day Source Difference）**：
通达信与官网同合约同日的量价仓超过已核验的表示精度后，受影响的派生指标暂停发布；原始来源事实和官网成交额继续保留。

**交易所投机标准保证金率（Exchange Speculative Margin Rate）**：
官网结算参数中的投机/一般持仓多头及空头标准，分别保存为0～1小数；套保率、公司加收率和合约文本最低保证金不能替代。中金所每个交易日按该日之前最近一次完整且已核验的官网公布表选取逐合约标准，直到下一次公布；参数公布日与使用交易日分别记录。最新表未列出的合约保持缺率，不向更旧表回退；其他交易所仍按各自同日有效证据选取。

**期货列表沉淀资金（Futures List Capital Deposit）**：
同日通达信期货名义市值分别乘以收盘结算时生效的交易所投机多头及空头保证金率后求和，两侧比例相同时等于单边资金的两倍。历史官网结算公式保留审计。

本文件定义项目中的统一业务语言。开发、测试、数据库、日志和文档必须使用这些术语，避免同一个概念出现多种含义。

## 行情与标的

**标的（Instrument）**：
可被观察、存储行情或运行策略的金融对象，例如股票、ETF、指数、期货合约和商品指数。
_Avoid_：证券、股票（用于泛指所有标的时）

**标准标的键（Canonical Instrument Key）**：
由国家或市场、交易所、资产类型和代码组成的项目内部唯一标识，不等同于任何数据源的代码。
_Avoid_：股票代码、来源代码

**来源代码（Source Symbol）**：
某个数据源用于标识标的的原始代码，只能通过映射关联到标准标的键。
_Avoid_：标准代码

**标的范围（Universe）**：
在某个生效日期由明确筛选规则产生的一组标的，例如“总市值大于 200 亿元的 A 股”。
_Avoid_：股票池（用于包含 ETF、指数或期货时）

**来源观测（Source Observation）**：
某个数据源在特定时间返回的原始数据记录，尚未被认定为项目使用的标准行情。
_Avoid_：标准行情

**宏观观测期（Macro Observation Period）**：
宏观数值所描述的统计月份、季度或交易日，不等同于发布或抓取日期。
_Avoid_：发布日期、数据更新时间

**宏观发布日期与抓取时间（Macro Released-at / Fetched-at）**：
`releasedAt` 是可由权威来源证实的公布时间；`fetchedAt` 是本机取得或写入该观测的时间。来源未提供可验证发布日期时前者为 `null`，两者不得互相代替。
_Avoid_：把本机时间称为官方发布时间

**来源能力（Provider Capability）**：
某数据源在特定操作、市场、资产类型、周期或数据类别上的可验证能力。每项能力独立记录状态、权限、限制、探测时间和证据，不能由同一来源的其他接口成功推断。
_Avoid_：来源支持（未说明具体能力时）、整源可用

**标准行情（Canonical Market Data）**：
经过代码映射、字段标准化、时间归属和质量检查后，被选为业务使用版本的行情数据。
_Avoid_：原始行情

**TDX 标准化版本（TDX Normalization Version）**：
通达信本地证券文件从原始二进制字段转换为标准 K 线所使用的可追溯规则版本。当前权威版本为 `tdx-cn-v2`；版本变更必须使旧检查点失效，不能混用不同版本的同一来源分区。
_Avoid_：默认转换、隐式倍率

**价格尺度（Price Scale）**：
将通达信原始价格字段转换为显示/计算价格所用的明确除数。它由资产类型、市场和周期确定，必须随每根正式 K 线保存，不能把所有日线一律按同一除数解释。
_Avoid_：通用 `/100`、猜测价格精度

**成交量量纲（Volume Unit）**：
标准化成交量的业务含义与候选倍率，例如证券股/份、指数原始量或回购千元面额。它与 `volume_multiplier` 一起保存，指数和回购不得伪装成证券股数参与聚合。
_Avoid_：全市场统一手数、无单位成交量

**隔离记录（Quarantined Record）**：
因资产分类不确定、量额关系无法唯一解释、OHLC 非法或质量检查失败而未写入权威 Silver 的来源记录及原因证据。隔离不是默认分类，也不是可直接展示的行情数据。
_Avoid_：其它行情、临时正式数据

**交易日（Trading Day）**：
交易所定义的数据归属日期；对期货夜盘而言，它可能不同于自然日期。
_Avoid_：日期、自然日

**统一交易日历（Unified Trading Calendar）**：
经来源标识和抓取时间留痕、供期货 Gold 任务共同使用的有效交易日集合；Silver 中出现的日期不能自行证明该日有效。
_Avoid_：Silver 日期集合、工作日列表

**交易时段（Trading Session）**：
一个市场或品种在某交易日内连续或分段交易的时间区间定义。
_Avoid_：开盘时间（用于表示完整时段规则时）

**市场分类（Market Category）**：
基于标准标的键及其显式市场、交易所和资产类型形成的筛选维度；代码规则和白名单只用于显式字段缺失时的兜底判定。
_Avoid_：仅凭代码前缀确定的市场

**交易场所（Trading Venue）**：
标的实际挂牌或成交所在的交易所，例如上期所、能源中心、大商所、郑商所、中金所、广期所、COMEX、NYMEX 或 CBOT。期货公开分类优先使用交易场所，不以“国内商品”或“全球期货”替代。
_Avoid_：数据源市场、全球期货、国内商品期货

**指数编制方（Index Administrator）**：
负责定义和维护指数规则的机构或来源系列，例如中证、国证、华证与通达信；它不同于成分证券的挂牌交易所。交易所自有指数单独归“交易所指数”。
_Avoid_：把所有中国指数称为 A 股指数、把编制方当作挂牌市场

**待分类标的（Unclassified Instrument）**：
标准字段或本地来源代码尚不足以唯一判定市场、交易所和资产类型的标的。它只进入内部审计结果，确认前不属于任何公开市场分类，也不进入正常行情列表、行情页面区块或策略扫描。
_Avoid_：其它市场、默认分类、先随便归类

**交易所品种分类（Exchange Security Category）**：
沪、深、北交易所按官方证券代码区间定义的品种，例如 ETF、可转债、可交债、债券回购、LOF 和公募 REITs；它是市场分类的细分维度，不等同于股票板块。
_Avoid_：把所有六位数字代码统称为 A 股个股

**期货品种键（Futures Product Key）**：
由交易所与规范化品种代码组成的内部唯一键，例如`SHFE.RB`；页面显示名为“中文品种名（代码）”，交易所身份保留在来源和明细中。
_Avoid_：脱离交易所的裸品种代码作为跨所唯一键

**期货品种上市交易日（Futures Product First Trading Day）**：
交易所首次允许某一期货品种交易的交易日，属于品种身份；若官方证据只精确到月份或年份，应保留该精度，不补造具体日期。
_Avoid_：具体月份合约挂牌日、合约文本发布日期、本项目首次采集日

**月份合约挂牌交易日（Dated Contract First Trading Day）**：
某一具体交割月份合约首次挂牌交易的交易日，同一品种的不同月份合约可以不同。
_Avoid_：期货品种上市交易日、交割日

**期货合约文本发布日期（Futures Specification Publication Date）**：
交易所发布某一版期货合约条款的日期；该版条款的生效日和品种首次上市交易日均须分别确认。
_Avoid_：期货品种上市交易日、条款生效日

**规范席位键（Canonical Member Key）**：
对交易所公布的席位名称进行确定性文本规范化后的精确键；商品席位跨交易所汇总只认完全相同的规范键，不做模糊相似度合并，别名只能来自显式审核的别名表。
_Avoid_：模糊合并席位、因中文名称相似而推断为同一公司

**排名发布方与采集适配器（Ranking Publisher / Adapter）**：
`publisher`记录发布数据的交易所，`sourceUrl`记录其具体官网文件/API，`adapter`记录本机使用的技术读取器；经第三方库包装访问官网不改变发布方，但必须在`legacyAdapter`或采集元数据中保留包装实现。
_Avoid_：把AKShare等客户端库显示成事实发布方

**通达信指数（TongdaXin Index）**：
通达信定义而非交易所挂牌的本地指数公开分类；`881` 行业系列和 `880` 综合系列在公开筛选中合并，内部仍保留各自系列类型。
_Avoid_：上交所指数、交易所挂牌指数

**其他债券回购（Other Bond Repo）**：
除通用质押式回购外，由沪深交易所官方代码区间定义的买断式、报价、协议、三方等回购业务内部分类；与“债券质押式回购”互斥。当前活动库存为零，不提供空的公开筛选项。
_Avoid_：泛化债券回购、把所有回购都称为通用质押式回购

**夜盘资格（Night-session Eligibility）**：
商品期货品种是否具有已配置夜盘时段的可叠加属性，不是独立资产类型；夜盘行情归属下一交易日。
_Avoid_：夜盘合约类型、自然日夜盘

**月份合约（Dated Futures Contract）**：
带有明确交割月份、由国内期货交易所挂牌的具体期货合约；到期后仍是历史交易日统计的组成部分，不包括主连、次连、加权连续或商品指数。
_Avoid_：主力品种、连续合约

**全月份合约范围（All-Month Contract Universe）**：
按所分析交易日判断仍有效且存在真实行情的全部具体月份合约集合；合约在当前日期是否到期不改变其历史交易日成员资格。
_Avoid_：品种范围、主力合约范围

**合约广度（Contract Breadth）**：
全月份合约范围中按相邻有效交易日收盘方向划分的上涨、下跌和平盘合约数量。
_Avoid_：品种涨跌家数、主力品种宽度

**合约方向（Contract Direction）**：
具体月份合约的当日收盘价相对该合约上一有效交易日收盘价的方向；缺少任一有效收盘价时方向未知，不能把缺数当平盘。
_Avoid_：品种方向、当前日期到期状态推断的历史方向

**沉淀资金（Futures Capital Deposit）**：
依据期货持仓、合约价值和当日有效保证金规则估算的多空双方保证金资金，不是账户实缴或可提取现金余额。
_Avoid_：成交额、持仓市值、客户保证金余额

**期货成交额（Futures Turnover）**：
某交易日具体月份合约的交易所公布成交金额；保留来源单位及单边或双边统计口径，同口径的合约值才可汇总为品种值。
_Avoid_：交易资金、沉淀资金、持仓名义规模、资金净流入

**品种官网成交额（Official Product Turnover）**：
同一交易所品种、同一交易日全部有效月份合约的已核验官网人民币成交额逐月合计，是v13气泡横轴。
_Avoid_：单月成交额、名义持仓规模、把未核验月份金额计零

**期货保证金规则快照（Futures Margin Rule Snapshot）**：
某一精确交易日的品种基础保证金率、具体合约保证金覆盖及来源证据；中金所快照注明实际官网参数公布日，按该日前最近完整公布表逐合约选取，其它交易所只用同日有效证据。名义持仓规模所需的交易乘数独立读取带官网证据和生效区间的乘数注册表。
_Avoid_：拿最新公布表未列出的合约从更旧表补率、把其他交易所旧率外推、把乘数缺失误作保证金规则缺失

**官方有效期合约乘数（Official Effective Contract Multiplier）**：
由交易所期货合约条款中的每手交易单位与报价单位确定、带`exchange + productCode + effectiveFrom/effectiveTo`的单位换算量；名义持仓规模只在核验过的生效区间使用。
_Avoid_：保证金率、涨跌停板幅度、每日交易参数、向未核验日期外推乘数

**持仓品种沉淀资金（Product Capital Deposit）**：
同一交易所品种、同一交易日全部有效月份合约的估算资金合计。逐月份以官网结算价×日期有效乘数×官网单边持仓量×（所选日适用的交易所投机多头保证金率+空头保证金率）计算后求和，是v14气泡大小的资金输入；视觉直径带可读性底座，面积不严格正比金额。中金所按最近完整公布表选率，其他交易所沿用同日门。任一有持仓月份缺两侧率或其它必需事实时完整合计为`null`，真实零与证据缺失分开。
_Avoid_：持仓品牌沉淀资金、单合约沉淀资金、名义持仓规模、期货公司实际收取保证金

**席位沉淀资金（Member Capital Deposit）**：
根据交易所公开排名中的会员多头和空头持仓估算的席位资金，只代表已公布排名覆盖范围。
_Avoid_：期货公司全部客户资金、全市场沉淀资金

**合约名义持仓规模（Contract Notional Open-Interest Value）**：
有效月份合约在某交易日按 `统一合约价格 × 合约乘数 × 交易所单边持仓量` 计算的名义规模；不乘保证金率，也不额外乘双边系数。页面可在用户标题中简称“市值”，接口、图注和公式必须使用本术语并声明价格口径。
_Avoid_：沉淀资金、双边市值、成交额、客户保证金

**品种名义持仓规模（Product Notional Open-Interest Value）**：
同一交易所品种在某交易日全部有效月份合约名义持仓规模之和；不重复加入主连、加权连续或指数序列。
_Avoid_：单合约市值、品种沉淀资金、全市场市值

**席位名义持仓规模（Member Notional Position Value）**：
交易所已公布排名覆盖范围内，会员某方向持仓按 `方向持仓量 × 统一合约价格 × 合约乘数` 计算并跨有效合约汇总的名义规模；只表示公开席位记录的覆盖范围。
_Avoid_：期货公司总资产、会员全部客户资金、全市场持仓市值

**品种持仓量（Product Open Interest）**：
同一交易所品种在某交易日全部有效月份合约的交易所单边持仓量之和，单位为张。
_Avoid_：成交量、双边持仓量、主连持仓量

**品种成交量（Product Trading Volume）**：
同一交易所品种在某交易日全部有效月份合约的交易所公布成交手数之和；它是当日成交活动，不是日末持仓，也不等于成交额。
_Avoid_：品种持仓量、成交额、把席位成交榜相加当作全市场成交量

**品种加权结算价（Product Weighted Settlement Price）**：
同一交易所品种在某个实际交易日，全部有效且有正单边持仓的月份合约结算价按各自单边持仓量加权得到的价格；月份成员和权重随日变化。它不同于某一个月份的结算价，也不同于将各月份价格直接相加。
_Avoid_：主连价格、单月合约价格、加总价格、通达信加权连续报价

**期货品种气泡（Futures Product Bubble）**：
以交易所和品种为稳定身份、代表该品种当日全部有效月份合约的分布点。v13横轴是品种官网成交额，纵轴是品种加权结算价最近十个连续核验实际交易日期的首尾涨跌幅，面积是持仓品种沉淀资金。v12横轴与面积使用名义持仓规模，属于历史口径。
_Avoid_：月份合约气泡、主力合约气泡、全部交易所同代码合并、将当前横轴或面积误称为市值

**交易所官方逐合约日事实（Official Exchange Contract-Daily Fact）**：
交易所按交易日、交易场所和具体月份合约发布的结算价、成交量、持仓量等字段；各字段分别保留单位、单/双边口径、来源URL、原始响应摘要、解析版本和质量状态。任一字段未核验时只影响依赖该字段的派生指标，不得据其它字段推算。
_Avoid_：把解析成功等同于每个字段均已核验、把未公布合约当作零

**官方回补请求预算（Official Backfill Request Budget）**：
按主机留痕的最小请求间隔、每日请求上限、失败暂停与重试时间；同一主机的请求需由持久OS锁串行预约，达到限额或遇到校验页时留给后续续跑。
_Avoid_：每次CLI运行重置限额、并发重试挑战页面、把暂停日标成成功

**席位持仓量（Member Position）**：
交易所已公布排名中会员的多头或空头方向持仓；毛持仓、多头净持仓和空头净持仓均由两个方向派生，且只代表公布覆盖范围。
_Avoid_：交易所全市场持仓量、期货公司全部客户持仓

**席位已公布毛持仓（Published Member Gross Position）**：
同一交易日、席位及商品下，交易所实际公布的多头和空头持仓张数之和；某方向未上榜时只合计已公布方向，不代表该方向实际为零。
_Avoid_：席位完整持仓、把未公布方向补零

**席位净多／净空持仓（Published Member Net Long/Short Position）**：
同一合约、交易日、席位的多空两个方向都有公布值时，分别取多减空、空减多的非负部分；缺任一方向时净值不可计算。
_Avoid_：仅凭单侧排名推算净持仓、将净值当保证金

**期货席位分布（Futures Member Ranking View）**：
从国内商品或金融期货品种及具体月份合约出发，查看交易所公布的席位多空持仓、净方向、名次及增减；品种显示中文名称和代码，内部身份仍包含交易所。
_Avoid_：商品席位分布、全部席位持仓、主连席位排名

**席位持仓分布（Member Futures Ranking View）**：
从规范席位名出发，跨国内商品和金融期货交易所汇总该席位已公布的品种、月份合约及多空持仓；末尾`（代客）`、`(代客)`归入同一展示身份，来源交易所、原名和排名事实仍逐条保留。
_Avoid_：期货公司全部客户持仓、全市场完整持仓品种

**席位成交排名（Member Trading Volume Ranking）**：
交易所公开的某合约席位成交手数、名次和公布的增减，独立于席位多空持仓排名；它不代表该合约全市场成交量。
_Avoid_：席位持仓排名、品种成交量

**跨所席位展示身份（Cross-Exchange Member Display Identity）**：
交易所公开席位名去空白并去掉末尾`（代客）`、`(代客)`后的展示身份，供跨所展示、筛选和同合约多空配对；其他不同名称不推断为别名。
_Avoid_：模糊名称合并、以席位展示身份替换交易所原始席位键

**固定堆叠基准（Fixed Stack Baseline）**：
旧版堆叠结构图使用的历史成员和顺序基准，只作公式审计。当前期货页的全部品种气泡不按此基准限制显示数量。
_Avoid_：每日动态排名、浏览器临时图例顺序、动态 Top-N

**品种结构前40名（Product Structure Top 40）**：
旧堆叠结构公式的历史成员范围；当前期货页气泡显示全部具有相应官网事实的品种，选择品种后才显示其历史线。
_Avoid_：每天重新选前40、按1.2%占比截取

**品种方向（Product Direction）**：
期货品种当日各月份合约按持仓量加权的结算价相对昨结算变化方向；完整周趋势由连续两个已结束交易周的周末结算价单独判定。
_Avoid_：合约方向、主力合约涨跌、买卖方向

**合约数量多空热度（Contract-Count Heat）**：
当前日方向广度按官网今结算相对前结算判断，先给品种相同基础权，再在品种内按当日持仓分配有效合约；原始上涨/下跌合约数量另外逐日展示，连续周不乘入此项。旧收盘方向及周总分公式留作审计。
_Avoid_：品种涨跌家数、未判断方向的合约补零、买卖信号

**连续周多空热度（Consecutive-Week Heat）**：
对当周有可核验周结算方向的全部活跃合约逐个计票。首个同向周、反向后的首周、平盘均无连续周加持；第二个同向周起按总票数2、4、8逐周倍增，其额外方向票为1、3、7。额外方向票的多空差占全体有效合约总票数的比例形成独立分数；缺报不能冒充零加持。
_Avoid_：把连续周倍数再乘入数量、幅度、成交额，单个持续合约直接代表全市场

**成交额多空热度（Contract-Turnover Heat）**：
v7及更早版本的历史指标：已核验交易所官网当日逐合约人民币单边成交金额，按今结算相对前结算方向加权形成方向分数。当前v8热度模块不显示该分数、图或成交额卡片；成交额原值仍供品种气泡横轴与来源审计使用。
_Avoid_：沉淀资金方向、成交量代替成交额、缺失成交额补零

**总多空热度（Composite Long-Short Heat）**：
当前v8按固定连续周60%、合约数量20%、加权涨跌幅20%组合的逐交易日期货市场展示指标，范围为`[-100,+100]`。数量和幅度每日更新，连续周只使用截至当日已结束周；缺任一评分分量时总分为空，有效方向全部不足连续两周时连续周分量为真实零分。成交额缺失影响来源覆盖和其它消费成交额的图，不改变三项评分权重或评分质量状态；v7的35/25/25/15记录留作历史审计。
_Avoid_：固定权重历史真值、买入信号、卖出信号

**多空热度（Long-Short Heat）**：
由每日方向广度、加权涨跌幅和最近已结束周的连续周加持三个独立分量形成的市场状态，仅消费六发布场所官网普通及月均价期货事实。日总分不沿用上周总分，旧公式版本只作审计留档。
_Avoid_：主力热度、沉淀资金多空方向、买卖信号

**连续周趋势权重（Consecutive-Week Trend Weight）**：
同一合约在已结束交易周持续同向上涨或下跌的趋势票数，首周总票数1且额外加持0；第二周起总票数2、4、8逐周翻倍且不设上限。只用于独立的连续周多空热度；反向重新从首周计数，缺报不推断连续性。
_Avoid_：当周未结束行情、无上限的热度分数、以缺报当平盘

**持仓加权结算变化（Open-Interest Weighted Settlement Change）**：
同一品种各期货合约的今结算相对昨结算变化按持仓量汇总的描述性价格变化，可逐日连乘为区间走势。
_Avoid_：文华商品指数、南华商品指数、真实持仓投资收益

**旧持仓与市值分布（Former Position and Notional Value Distribution）**：
旧版双轴气泡以品种持仓量为横轴、名义持仓规模为纵轴、成交额为面积；现行页面使用单张期货品种气泡，界面“市值”仍专指名义持仓规模。
_Avoid_：账户权益、保证金占用、现货总市值

**市值与涨跌分布（Notional Value and Return Distribution）**：
每颗气泡代表一个交易所内的一个品种及其全部有效月份：横轴和面积为同日逐月名义持仓规模之和，纵轴为最近十个实际交易日期的品种加权结算价首尾变化；逐月成交额之和显示在右侧历史线。月份构成变化可改变加权价，月份合约首次出现不等于品种首次出现。
_Avoid_：以单个月份合约代表品种、以单月缺少十日历史判整个品种缺报、将成交额当名义持仓规模

**旧气泡横轴逐日变化（Former Bubble Horizontal Daily Difference）**：
旧版四张分布气泡图使用今日横轴百分比减去上一实际交易日横轴百分比的纵轴，单位为百分点／交易日；现行单张市值与涨跌分布不用此坐标。
_Avoid_：相对增速、三日平滑、连续周数、自然日差值

**行情分区（Market Partition）**：
按市场、资产类型、周期和日期范围划分的数据发布与主备切换最小单位。
_Avoid_：表、文件（用于表达业务边界时）

## 数据生产与交付

**客户产品入口（Customer Product）**：
供产品客户研究行情、使用策略并维护个人研究数据的界面；客户身份不包含平台运行管理权限。
_Avoid_：前端（用于代替客户角色）、管理员客户端

**内部管理台（Internal Console）**：
供获授权的项目工作人员管理数据生产、服务运行和内部诊断的工作界面；其操作对象是平台运行状态。
_Avoid_：后端页面（用于代替员工角色）、客户设置页

**本机管理员（Local Administrator）**：
在本机开发部署中管理该项目运行环境的操作者；不等同于已建立员工账号或已获公网管理权限的用户。
_Avoid_：所有客户、默认员工账号


**数据生产端（Data Producer）**：
运行在个人电脑或可选云主机上，负责采集、清洗、聚合、扫描策略和生成数据包的程序。
_Avoid_：后端（容易被误解为手机必须连接的在线服务）

**Android 消费端（Android Consumer）**：
导入并查询数据包、维护个人数据、展示行情和执行受支持策略的 Android 13+ 应用。
_Avoid_：手机客户端（用于暗示它依赖在线服务器时）

**行情包（Market Package）**：
由数据生产端生成、签名并发布给 Android 消费端的不可变版本化行情数据集合。
_Avoid_：数据库备份、同步文件

**策略包（Strategy Package）**：
面向 Android 的受信任、签名声明式 DSL 可导入集合，包含版本、参数定义、输入要求和共享测试向量。Android 只解释白名单 DSL 节点，不执行 Python。
_Avoid_：脚本文件、Python 包、插件（除非以后真的形成通用插件体系）

**桌面策略传输包（Desktop Strategy Transfer Package）**：
只面向桌面端的 ZIP 格式，包含一个 custom Rule-AST Strategy Definition、精确 Strategy Function Dependency Lock、权威 Schema、测试向量和每个内容的 SHA-256；可附 Ed25519 Manifest 签名。导入预览必须在内存中完成布局、尺寸、摘要、Schema、AST、函数版本和冲突校验，且只能由明确的改名/连续新版本操作写入。它固定 `target=desktop`，即使签名有效也不是 Android 策略包。
_Avoid_：凭据、账户、运行数据、真实订单、Android 兼容性声明、任意代码

## 策略系统

**操作信号策略（Action Signal Strategy）**：
历史四类独立观察规则，分别产生开仓、加仓、减仓或平仓信号；其定义及既有记录保留为历史资源，现行策略采用组合策略。
_Avoid_：真实下单策略、回测资源、已成交订单

**信号监控轮次（Signal Monitoring Cycle）**：
同一标的同一多空方向从开仓信号开始、到平仓信号结束的一轮观察；期间才监测同向加仓、减仓和平仓信号，同一时点平仓优先。
_Avoid_：真实持仓、账户头寸、自动交易

**盈亏比画线（Risk/Reward Drawing）**：
以用户设定的开仓参考价、止损参考价和目标参考价显示多头或空头风险收益距离之比的图形，不表示实际订单或策略触发。
_Avoid_：真实盈亏、收益预测、止损指令

**策略函数（Strategy Function）**：
接收明确输入并返回确定性结果的无副作用、可版本化计算单元，可同时被指标和策略引用。
_Avoid_：指标算法副本、带账户状态的函数、下单函数

**指标（Indicator）**：
把行情或外部市场数据经策略函数计算后的结果投影到 K 线主图或副图的可视化资源；它不读取账户、订单或持仓，也不产生订单意图。
_Avoid_：策略、交易信号、直接下单指标

**指标实例（Indicator Instance）**：
某个指标确定版本在一张当前图表上的一次配置，拥有独立参数、样式、可见性和主图或副图位置；同一指标可同时存在多个实例。
_Avoid_：指标定义、共享算法副本、固定图表键

**VIX 外部市场指标（VIX External Market Indicator）**：
仅将有来源证据且 `sourceStatus=PASS` 的本地 `US.CBOE.INDEX.VIX` 标准日序列按显式交易日投影到当前图表副图；响应同时带来源、数据截至日、覆盖与精确对齐点。无源、来源失败或无重叠交易日均不可用，日期缺口为 `null`。
_Avoid_：从当前标的 OHLC 计算 VIX、前值填充、浏览器直连第三方、把 fixture 当作真实来源

**成交量分布（Volume Profile）**：
在一个显式、闭区间的 K 线窗口中，将每根 bar 的全部 `volume` 归入其 HLC3 所在的等宽价格桶所得的主图范围型 Plot；POC 是量最大的桶，价值区从 POC 向相邻桶按成交量扩张。缺少或为零的成交量即不可用，不能由 `amount` 替代。
_Avoid_：逐价格成交明细、由成交额猜测的成交量、冻结在旧缩放区间的横向柱图

**斐波那契回撤画线（Fibonacci Retracement Drawing）**：
由用户明确绘制的两个逻辑时间/价格锚点和带标签比例构成的 `drawing_tool`；第 0 比例在第二锚点、第 1 比例在第一锚点，其他价格从二者线性回撤计算。它是个人画线数据，不是市场指标或策略输入。
_Avoid_：技术指标、Strategy Function、屏幕像素坐标、由行情自动推断的锚点

**相对波动指数（Relative Volatility Index, RVI）**：
Donald Dorsey 的 0 至 100 波动方向指标：将滚动标准差按收盘价涨跌日拆分并平滑。本项目固定采用 1993 close-based 版本，不能与 Relative Vigor Index 同名缩写混用。
_Avoid_：Relative Vigor Index、未声明版本的 RVI

**Twiggs 波动率公开变体（Twiggs Volatility ATR% Public Variant）**：
以 `100 × Wilder ATR / close` 可复算的 ATR 百分比实现，用于表达“基于 ATR 的公开变体”；Twiggs® 原始专有算法未被声称为已复现。
_Avoid_：Twiggs® 精确公式、未标注来源的同名指标

**策略（Strategy）**：
当前页面中的策略指同时包含关注、仓位、择时三部分的组合策略；各部分引用预先定义的策略函数，产生观察结果与配置建议。
_Avoid_：指标脚本、真实持仓、下单指令、历史回测策略

**关注策略（Attention Strategy）**：
决定是否持续观察某个标的及其多空方向的规则，包含进入与取消关注条件；同期表现是相同真实比较时间段的方向与涨跌幅，不等于因果带动关系。
_Avoid_：开仓信号、必涨必跌预测

**仓位策略（Position Strategy）**：
仅对已关注标的计算盈亏比、胜率证据、建议配置比例、资金使用率和杠杆率的规则；缺少数据时保留不可用，建议比例不表示账户实际仓位。
_Avoid_：真实持仓、保证收益率、默认胜率

**择时策略（Timing Strategy）**：
仅对已关注标的产生开仓、加仓、减仓、平仓时机的规则；加减平仓依赖先前开仓，平仓后可在仍关注时再次开仓。
_Avoid_：独立开仓策略类别、真实成交

**组合策略（Composite Strategy）**：
一个同时具备关注、仓位、择时三类规则的完整策略；同一标的可被多个组合策略分别观察，目标行情按组合策略区分这些结果。
_Avoid_：只有单类规则的完整策略、把多个观察结果合并为账户仓位

**观察胜率（Observed Win Rate）**：
同一组合策略版本、同一标的的已结束开平仓信号轮次中，方向价格变动为正的轮次比例；它不含费用及真实成交，也不代表未来胜率。
_Avoid_：预测胜率、缺样本时的默认百分比

**历史回测策略（Legacy Backtest Strategy）**：
先前轮次中组合标的范围、规则、仓位和风控以模拟订单意图的版本化研究资源；它与现行组合策略是不同资源，已有定义和运行结果仍是历史证据。
_Avoid_：当前策略页默认资源、信号监控轮次、真实交易

**订单意图（Order Intent）**：
策略提出但尚未执行的结构化开平仓请求，必须通过风险引擎后才能交给执行适配器。
_Avoid_：真实订单、成交、策略信号

**能力上下文（Capability Context）**：
由桌面服务端根据已保存且通过校验的精确资源版本签发的运行权限，包含资源层、平台和允许能力；客户端提交的 `resourceType` 或按钮可见性都不是授权依据。
_Avoid_：前端权限、客户端自报角色、可修改的权限标签

**风险裁决（Risk Decision）**：
风险引擎对一个订单意图和当次账户/行情上下文作出的 `accepted/rejected/not_evaluated` 结构化结论；没有 `accepted` 裁决不得进入执行适配器。
_Avoid_：策略信号、执行结果、前端确认

**执行适配器（Execution Adapter）**：
只接收已绑定风险许可且运行模式一致的订单意图的隔离端口。回测与模拟盘使用不同适配器；未配置并验收的实盘适配器不存在于可用能力中。
_Avoid_：策略内下单函数、通用券商对象、把模拟接受称为真实成交

**策略运行模式（Strategy Run Mode）**：
策略执行的隔离环境，规范值为回测、模拟和实盘；未配置合格执行适配器时实盘模式不可用。
_Avoid_：把回测或模拟标记为实盘

**策略报告（Strategy Report）**：
针对确定策略版本、参数版本和数据版本生成的可复现回测结果，包含绩效、权益、交易记录、成本和不可用原因。
_Avoid_：实盘业绩、只有汇总值的扫描结果

**热数据（Hot Market Data）**：
Android 端为日常查询和轻量扫描保留的近期标准行情及派生结果。
_Avoid_：全量数据

**冷数据分片（Cold Market Shard）**：
按市场、周期和年份拆分、按需加载的只读历史行情文件。
_Avoid_：热数据库

**数据截止时间（Data Cutoff）**：
某一行情分区实际包含完整数据的最后时间，每个分区单独记录。
_Avoid_：更新时间（不能表达数据是否完整）

## 策略与个人记录

**策略定义（Strategy Definition）**：
描述策略身份、输入、参数、声明式计算图、输出和版本的稳定契约。
_Avoid_：策略结果

**策略模板（Strategy Template）**：
不可变的 builtin 创建起点，公开 `templateId/version/sourceStrategyVersion/defaultOverrides`、依赖、风险/参数预览和非收益承诺说明；选择它必须生成独立 custom Strategy，不能编辑或共享修改模板来源。
_Avoid_：可变共享策略、盈利承诺、未校验的配置片段

**来源信任元数据（Strategy Trust Metadata）**：
为未来 `community/plugin` 资源预留的发布者、可选签名键指纹及验证结论、信任状态和审核状态。当前它只支持识别与显示：community/plugin 固定 disabled，且无论签名或信任字段如何声明都不能执行、复制、升级或获得订单权限。
_Avoid_：当前已实现的社区市场、自动信任升级、由前端或签名直接授予执行权

**依赖锁（Dependency Lock）**：
一次回测持久化的精确可复现依赖快照：Strategy 与每个 Strategy Function 的 `id/version/definitionHash`、图表指标依赖列表、参数值及哈希、行情版本/哈希/查询窗口和回测引擎版本。当前 Rule AST 不能执行图表 Indicator，因此其列表必须显式为空而不是以 latest 代替。
_Avoid_：只记录策略名称、运行时查最新资源、缺失版本时静默回退

**历史回测复现（Historical Backtest Reproduction）**：
仅使用某回测运行的 Dependency Lock 所列精确版本和原行情窗口重新执行的校验流程。任一策略/函数定义哈希或行情哈希不一致、版本缺失时必须以结构化错误停止，不能输出伪造的“复现成功”。
_Avoid_：更新后重新回测、latest 回放、忽略数据版本差异

**策略规则树编辑器（Strategy Rule Tree Editor）**：
对 `entryRules` 或 `exitRules` 的规范 Rule AST 进行递归可视编辑的界面能力；AND/OR/NOT、条件、函数调用、操作数及排序直接映射到树值，函数签名和资产适用性来自注册表，保存时才按契约转换字段名。
_Avoid_：模板降级、可执行表达式字符串、临时 UI 节点 ID、绕过服务端版本/类型校验

**策略 DSL（Strategy DSL）**：
由版本化 Schema 约束的声明式策略语言，只允许已登记的指标、运算符、条件和信号输出；不包含任意代码、网络或文件访问。
_Avoid_：Python 脚本、可执行插件

**策略运行（Strategy Run）**：
某个策略版本在指定数据版本和参数版本上的一次执行记录。
_Avoid_：策略

**回测运行（Backtest Run）**：
Strategy Run 的隔离回测形式：规则仅使用当根及历史 bar，在信号 bar 结束后按已声明的下一根成交时点模拟 `OrderIntent → Risk Decision → Backtest Fill`，并锁定策略、函数、参数及数据指纹。
_Avoid_：扫描结果、实盘订单、使用未来价格的回放

**回测成交（Backtest Fill）**：
由 Backtest Execution Adapter 依据已接受 Order Intent、成交模型、费用和滑点生成的模拟成交事实；它不是券商回报或真实成交。
_Avoid_：真实订单、策略信号、无成本的虚拟交易

**策略信号（Strategy Signal）**：
策略运行产生的候选标的、触发条件、观察理由和风险标签，不代表投资建议或自动交易指令。
_Avoid_：买卖指令、荐股

**个人数据（Personal Data）**：
用户创建的自选、交易历史、资金记录、策略参数和人工确认内容，所有权独立于行情包。
_Avoid_：行情数据

**Day 0 闭环（Day 0 Vertical Slice）**：
使用少量真实代表标的，完整验证采集、标准化、质检、打包、Android 导入、展示和策略执行的第一条可运行链路。
_Avoid_：全市场上线、完整 MVP

_状态说明（2026-08-04）_：Day 0 已停止且未封板；该术语仅保留其架构与历史验收含义，不构成后续会话的自动工作指令。

## 任务治理

**开发轮次计划（Development Round Plan）**：
根目录 `Plan_RN.md` 中编号为 `RN-Txxx` 的当前开发台账；同一时刻只有最新轮次可作为活动计划，较早轮次只保留历史事实与证据。当前活动计划为 `Plan_R4.md`。
_Avoid_：同时在 R1、R2、R3、R4 或历史 STATUS 中维护相互冲突的当前待办

**正式任务（FULL Task）**：
`Plan_full.md` 中定义、由 `STATUS.md` 跟踪的单一可审查交付单元。实现、审查和验收由独立任务完成。
_Avoid_：把多个 `FULL-*` 合并为一次实现

**实时状态源（Live Status Source）**：
当前开发轮次计划对任务状态、证据、阻塞和下一项任务的唯一记录；`STATUS.md` 保留旧 `FULL-*` 正式任务历史。
_Avoid_：在交付报告、README 或历史计划中维护平行待办表

**连续序列分类（Futures Continuous-Series Category）**：
由标准标的元数据的 `seriesKind=MAIN|WEIGHTED` 决定的国内期货市场目录项，分别公开为“国内期货主连合约”和“国内期货加权合约”。夜盘是交易时段 metadata，不是展示分类。
_Avoid_：在 UI 解析来源代码后缀、把夜盘当作可筛选资产类别、为无数据品种制造连续合约

**行情列表快照（Market List Snapshot）**：
按逻辑标的从一个已选真实日线来源得出的最新字段、字段能力、来源/截至日、不可用原因和交易日收益率集合；列表、看板与详情引用同一语义。
_Avoid_：每个单元格独立请求历史、将缺失字段补为 0、浏览器伪造收益率

**交易日窗口涨幅（Trading-Day Window Return）**：
对 N 根有效日线的收益率，计算 `100 × (最新收盘 / 前 N 根有效交易日收盘 − 1)`，因此至少需要 N+1 根合格日线。
_Avoid_：自然日补周末/节假日、混用来源或复权口径、零基准返回 0

**续2 图表布局（R4-S2 Chart Layout）**：
历史续2显示规则，已由续3量柱与额/持仓折线规则覆盖；历史实现与验收证据保留在第四轮台账。
_Avoid_：将历史显示规则误认为当前需求

**行情涨幅显示（Market Return Display）**：
以百分数为单位的真实涨幅；当日和各交易日窗口分别有自己的正负方向。最新价的颜色方向引用当日涨幅，零和缺失不属于上涨或下跌。
_Avoid_：将全部窗口按当日方向着色、把百分数再乘100、按显示字符串判方向

**持仓量显示能力（Open-interest Display Capability）**：
由同一标的字段能力或已取得真实持仓量观测确认的显示资格，零持仓量仍是有效观测；最新一根缺值不能否定已确认资格。
_Avoid_：按市场名称猜测、把最新快照缺值解释为该品种永远不支持持仓量
